Project: Altius Group – Premium Real Estate, Property Development & Luxury Short Lets

Design and build a premium, modern, elegant, high-converting corporate website for Altius Group, a Nigerian real estate and investment company headquartered in Lekki, Lagos.

The website should immediately communicate trust, luxury, professionalism, and investment expertise while making it effortless for visitors to explore available properties, book luxury short-let apartments, contact agents, or invest.

The design should feel comparable to Sotheby's Realty, Eko Atlantic, or other world-class property companies while remaining authentic to the Nigerian market.

Realism

Every screen should feel production-ready.

Every image should appear professionally photographed.

Use realistic Nigerian locations, architecture, interiors, and people.

Avoid generic placeholder illustrations.

Design every page as if the website is launching for a premium real estate company today.

Apply the following content and markup standards to every page in this site
CONTENT STRUCTURE
Direct-Answer Opening: Immediately below the H1 on every page, add a "quick-answer" block of 60–100 words that directly answers the primary question that page targets. Plain sentences, answer-first, without marketing fluff.
One Topic Per Page: Each page must have exactly one H1 mapped to one primary topic. Do not combine multiple services on a single page.
Bulleted Data Points: Present pricing, features, timelines, specifications, and other factual information as bullet lists rather than long paragraphs.
NAP Block: Create one reusable <address> component containing the Altius Group office details, rendered identically in the footer, Contact page, and other location-relevant pages.
Named Source Claims: Attribute any statistics, pricing comparisons, market trends, or performance claims to a named source or internally dated report.
SEMANTIC HTML
Use <header>, <nav>, <main>, <article>, <section>, and <footer> appropriately.
One <h1> per page.
Proper <h2> and <h3> hierarchy.
Every image must include descriptive alt text.
Build an FAQ component using <h3> (or <summary>) for questions and a <p> directly beneath for answers.
STRUCTURED DATA (JSON-LD)

Generate appropriate structured data for each page using real page content:

Organization
LocalBusiness
RealEstateAgent
Residence (where applicable)
Product (investment packages if applicable)
FAQPage
Review
PERFORMANCE
Mobile-first responsive design.
Lazy-load below-the-fold images.
Optimize image sizes.
Minimize unnecessary animations.
Maintain excellent Core Web Vitals.
Keep component bundles lightweight.
Engineering Note

Figma Make outputs a React application. For strong SEO and AI discoverability, ensure the final production deployment uses Server-Side Rendering (SSR) or Static Site Generation (SSG) (such as Next.js). A purely client-rendered React SPA can leave crawlers with an almost empty initial HTML document, significantly reducing search engine indexing and AI visibility. Use SSR/SSG to ensure all page content and structured data are present in the initial HTML response.
